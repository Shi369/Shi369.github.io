第二天2026.8.7

  2. 掌握CSS用法，包括选择器和文字控制属性

第三天2026.8.8

今天学习开始有点吃力了，难度增大，内容变多。
主要内容是CSS选择器和样式的学习，通过Emmet提高编程效率。了解了盒子模型（块级元素、行内元素特点与区别）。学习过程不是很顺利，效率低下，明天尝试改变学习方法，采用间歇法，适当安排休息时间，相同时间内提高每一次学习的专注力。

第四天2026.8.9

  1. pxcook像素大厨：前端开发标注工具，切图工具。
  2. 对盒子模型知识进行巩固，跟着方案实操
  3. 难度继续增长，理论的学习、实践花费时间增多，代码量变大

坚持就是胜利

第五天2026.8.10

主要学习内容：Flex布局
感觉比较吃力，特别是父元素子元素、块级元素行内元素的实际显示效果，前段CSS新名词数量多，学习速度较慢，我打算今天不再预习后面的内容，使用一整天的时间结合实际案例反复练习，吃透这一部分内容。

第六天2026.8.11

实战制作网页，综合运用各类方法和CSS布局，按照先构建前端盒子，从整体后局部，从上到下，从外到里的思路依次进行。
