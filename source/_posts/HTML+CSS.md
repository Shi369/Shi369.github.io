总结：代码不必死记，核心是你知道用法和逻辑，想不起来具体代码及时查资料即可，比如：  

```Javascript
<script>
document.addEventListener('DOMContentLoaded', function(){
    // 这里写你的代码，所有DOM已经渲染完成
    console.log('dom加载完毕');
})
</script>
```
*该用法只需要记得在Dom加载完后执行Script即可查到*
